# Test material

| Folder or file | What is in it |
|---|---|
| `ai/` | 16 machine drafts. Numbers 01 to 08 may be read when writing rules. Numbers 09 to 16 are held out: scored, never read while writing a rule. |
| `human/` | 16 pieces of human writing from 2021, with their sources in `SOURCES.md`. |
| `briefs.json` | The requests the machine drafts were written from. |
| `regressions/cases.json` | Every mistake the checker has made so far. Each one must stay fixed. |
| `baseline.json` | How many planted errors the checker caught last time. CI fails if it catches fewer. |
| `trial/` | The same drafts rewritten in different ways, one folder per way. |
| `reader/` | The blind sheet for a person to judge, and its answer key. |
| `results/` | The saved numbers behind the README. |

The texts here are test material. Do not tidy their spelling or spacing.
